I build tools for the work that keeps accountants stuck in tabs, spreadsheets and repeat clicks. My focus: **GST workflows, Tally automation, bank statements and applied AI**. I like software that is useful in practice, checks its own output and treats client data with care.

> With great power comes great responsibility. With great automation comes one more check before you hit **Import**.

### The toolkit

| Project | What it does |
| :-- | :-- |
| [TaxFlow Pro](https://github.com/nandeeshbalekoppadaramane/TaxFlow-Pro) | Helps CA teams move GST data into TallyPrime, with review before export and posting. |
| [TallyBridge](https://github.com/nandeeshbalekoppadaramane/TallyBridge) | Turns bank statements into Tally-importable vouchers in a browser-based workflow. |
| [Bank Statement Converter](https://github.com/nandeeshbalekoppadaramane/Bank_Statement_Converter) | Converts text-based Indian bank statement PDFs into structured Excel. |
| [GST Returns Downloader](https://github.com/nandeeshbalekoppadaramane/GST_Returns_Downloader) | Cuts down month-by-month clicking when downloading GST returns. |
| [Unlimited OCR](https://github.com/nandeeshbalekoppadaramane/Unlimited-OCR) | Experiments with long-document OCR and resumable processing. |
